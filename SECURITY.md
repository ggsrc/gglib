# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on <https://github.com/ggsrc/gglib>.
Do not open a public issue for a suspected vulnerability.

Include the affected module (for example `grpc` or `interceptor`), the module
version or commit, and a minimal reproduction if you have one.

## Supported versions

Only the latest released minor version of each module receives fixes.
Modules are versioned independently; see the [README](README.md#versioning).
