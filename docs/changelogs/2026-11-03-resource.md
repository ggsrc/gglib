# fix(resource): stop everything, name errors, keep the caller's context

Tracking: alva-ai/mono-meta#1115 (gglib, per-module PR). Stacked on #31.
**Stop now runs in reverse registration order** (decision G12 = A). alfs and
stream-relay must reverse their registration order when they upgrade; see
"Consumer impact".

## 1. Current state

Review (lifecycle RES-1 … RES-6), proven:

- `Stop` returned at the first error, leaking later resources.
- `Start` handed resources an errgroup context canceled when `Start`
  returned; it ran in parallel; a failure stopped everything and printed to
  stdout with `fmt.Printf`.
- `Stop` ran in registration order, so a dependency registered first (a
  database pool) closed before the resources that use it. alfs and
  stream-relay register the users first on purpose, with a comment saying
  why; worldline wraps the manager to reorder it.
- Errors carried no resource name; `OK` returned only the first failure.
- `AddResource` was not concurrency-safe; `HealthStatus` was dead code.
- No tests.

## 2. Behavior after this change

- `Init`: in order, first error returned with the resource name.
- `Start`: in order, with the caller's context; on failure, stops every
  resource and returns the start error joined with stop errors.
- `Stop`: every resource is stopped, **in reverse registration order**;
  errors joined and named; only the first call acts. A failed `Start` stops
  in the same order.
- `OK`: every failing resource reported, by name.

Consumer impact: alva-backend, alfs, worldline, stream-relay and llm-data
call `Init`/`Start`/`Stop`/`OK` the same way. alva-backend calls `Stop`
itself and through `app`; the second call is now a no-op. Error texts gain a
`resource <name>: <phase>:` prefix.

Stop order, per service, when it upgrades:

- alfs, stream-relay: they register the users before the dependencies so
  that the users stop first. Reverse the registration order (dependencies
  first) and drop the comment. If missed, a dependency closes while its user
  still runs: a few errors during rollout, like alfs on STG on 11-02.
- worldline: the wrapper that reorders Stop can be removed.
- alva-backend, llm-data: check that dependencies are registered before
  their users.

## 3. Decisions

- G12 = A: reverse order, the usual Go convention (like `defer`); register
  dependencies first.
- Sequential `Start`: matches `Init` order and makes failures
  deterministic. Every current `Start` is non-blocking.
