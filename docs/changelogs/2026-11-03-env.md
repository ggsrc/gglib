# fix(env): fail-safe environment detection, tests, no init

Tracking: alva-ai/mono-meta#1115 (gglib, per-module PR). Stacked on #31.
Decision G6 = A (Yumin, 2026-11-03): unknown environment values count as
production.

## 1. Current state

- `IsProduction` was true only for an exact `ENV=prd`. `PRD`, `prod`, a
  typo or a leading space counted as "not production", and `grpc` uses
  `!env.IsProduction()` to record request and response bodies in spans
  (review EN-1).
- `Env()` fell back to `OTEL_DEPLOYMENT_ENVIRONMENT`, but the `Is*` functions
  did not: `ENV=""`, `OTEL_DEPLOYMENT_ENVIRONMENT=prd` gave `Env()=="prd"`
  and `IsLocal()==true` (EN-2).
- Name, version, host and build time were read once in `init()`; the
  first-call-wins setters raced with the getters under `-race` (EN-3).
- No tests.

## 2. Behavior after this change

- `Env` trims and lower-cases the value and maps aliases to canonical names
  (`prd`/`prod`/`production` → `prd`, `stg`/`staging` → `stg`, `beta`,
  `test`, empty or `local` → `local`). Other values are returned as given
  (trimmed, lower-cased).
- `IsProduction` is true for `prd` and for every unrecognized value. The
  other `Is*` functions are derived from `Env`.
- `ServiceName` = `SERVICE_NAME` → `OTEL_SERVICE_NAME` → `UnknownService`;
  `ServiceVersion` = `SERVICE_VERSION` → `GIT_SHA` → VCS revision → `""`.
  Both read the environment on every call.
- Removed unused API: the setters, `HostName`, `BuildTime` and their
  `Unknown*` constants (no user in 45 repositories or in gglib).

Consumer impact: deployments set `ENV=prd|stg|beta` exactly (gitops
templates), so nothing changes for them. alfs and llm-data use only `Env`,
`IsProduction`, `IsUnitTest` and `ServiceName`.

## 3. Decisions

- G6 = A. Accepted aliases are deliberately few; `dev` or `development`
  count as production rather than guessing.
- Values are read live: `os.Getenv` is cheap, and tests can use `t.Setenv`.

## 4. Changes

- `env/env.go`, `env/service.go` rewritten; `env/build.go`, `env/host.go`
  deleted; `env/env_test.go` added.
- `.golangci.yml`: the temporary `gochecknoinits` exclusion for env removed.
- Coverage floors (`<module>/.coverage-floor`): env floor 0 → 100.
- `env/CHANGELOG.md`.
