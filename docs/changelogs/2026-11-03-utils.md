# fix(utils): keep the caller's span kind and options; deprecate the package

Tracking: alva-ai/mono-meta#1115 (gglib, per-module PR). Stacked on #31.
G1 listed utils as "deprecate first, delete after its user moves" (alfs's
cron example, 1 call site; that file changes anyway because it also uses
the removed `resource/hatchet`).

## Changes

- `StartTrace` no longer overwrites the caller's span kind and uses the
  current global tracer provider; `BackgroundCtx` applies its options.
- Instrumentation scope `github.com/ggsrc/gglib/utils` instead of the stale
  `github.com/ggsrc/app`; no `service.name` span attribute (the resource
  carries it); no `gglib/env` dependency.
- Package marked `Deprecated`: use `otel.Tracer(...)` directly.
- Tests at 100%; the temporary lint exclusion for utils is removed
  (otel's stays until #40).

- `make tidy-check build vet test lint cover` — all modules pass.
